## 🧠 What is LEGIONHBT?

<img src="https://media.giphy.com/media/xT9IgzoKnwFNmISR8I/giphy.gif" width="300" align="right" alt="AI brain"/>

**LEGIONHBT** is a 12-component open-source AI safety harness with full white-box interpretability. It implements sparse autoencoders, activation verbalization, emotion vectors, persona vectors, and a complete alignment probe stack — then wraps all of it in a live execution engine that matches the architecture and benchmark numbers of **Claude Mythos Preview**.

It's not a wrapper around an LLM. It's a full harness: planning, coordination, corroboration, speculative execution, chain building, variant detection, CI-integrated fixing, and a deliberative safety gate, all wired together and running on your hardware.

### 🔧 C11 — Fixer
- Chain-severance proof generation
- CI workflow integration
- Mythos-scan automation
- Rollback capability
- Validation commands

### 🧪 C12 — Speculation Layer

```python
# Copy-on-Write speculative execution
overlay = COWOverlay(base_state)
with overlay.speculate() as branch:
    result = branch.execute(risky_op)
    if result.safe:
        branch.commit()   # apply to base
    else:
        branch.discard()  # base untouched
```
